Installation
============

``structtype`` may be installed via ``pip`` or ``uv``. Note that Python >= 3.10
is required. The basic install has no required dependencies. Pre build wheels are
available.

**pip**

.. code-block:: shell

    pip install structtype

**uv**

.. code-block:: shell

    uv add structtype


Installing from GitHub
----------------------

If you want wish to use a feature that hasn't been released yet, you may
install from the `main branch on GitHub
<https://github.com/tds333/structtype>`__ using ``pip``:

.. code-block:: shell

    pip install git+https://github.com/tds333/structtype.git
