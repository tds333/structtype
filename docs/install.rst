Installation
============

``structtype`` may be installed via ``pip`` or ``conda``. Note that Python >= 3.10
is required. The basic install has no required dependencies.

**pip**

.. code-block:: shell

    pip install structtype

**conda**

.. code-block:: shell

    conda install structtype -c conda-forge


Installing from GitHub
----------------------

If you want wish to use a feature that hasn't been released yet, you may
install from the `development branch on GitHub
<https://github.com/tds333/structtype>`__ using ``pip``:

.. code-block:: shell

    pip install git+https://github.com/tds333/structtype.git
